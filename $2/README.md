# `$2` 전체 작업 기록

이 폴더는 실험 1~7을 각각 정리한 자료가 아니다. 대화가 시작된 2026-08-29부터 현재까지 실제로 수행한 작업을 시간순으로 복원한 기록이다.

전체 내용은 [`전체작업기록/README.md`](전체작업기록/README.md)에서 시작한다. 데이터 흐름, 모델 구조, 학습 설정과 성능을 한눈에 보려면 [`전체기술보고서.md`](전체작업기록/전체기술보고서.md)를 먼저 본다.

## 구성

- `001~007`: 원본 누락점검, 역순 싱크, MATLAB 재검증, 원시 마커 비교, 엑셀 전수검사와 표시 보강
- `008~013`: 초기 SNN, 목표 재설계, 실험 1·2 라벨링·모델비교, 숨참기 심박 탐색
- `014~016`: 발표 피드백 반영, 멀티패스·방향 분석, 10명 개발 신호처리
- `017~022`: 27명 경계·창 생성, ANN/SNN 정식 교차검증, 필터 비교, 파형 데이터셋·파일럿, 독립 실행 확인
- `023`: 현재 결론과 다음 단계
- `024`: 전체 기술보고서 편찬과 시각자료 정리

각 번호 폴더의 `상세작업기록.md`에는 요청, 수행 내용, 설정, 판단 이유, 결과, 한계와 다음 단계가 적혀 있다. 관련 엑셀·워드·모델·코드·수치 결과는 같은 번호 폴더 아래 `산출물`, `코드`, `결과자료`에 배치했다.

저장소에 넣지 않은 원시 생체데이터와 중간 체크포인트는 [`누락_제외_대체목록.md`](전체작업기록/누락_제외_대체목록.md)에 이유와 대체 자료를 적었다.
