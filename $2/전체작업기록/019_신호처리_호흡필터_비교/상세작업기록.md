# 019 신호처리와 호흡필터 비교

## 왜 신호처리 기준선을 비교했는가

UWB 호흡 측정은 흉곽 움직임이 만드는 위상 변화를 호흡 주파수 대역에서 찾는 문제다. 이미 물리적으로 의미 있는 대역통과, 스펙트럼 피크, 3레이더 합의 같은 방법이 있으므로 학습모델은 이 기준선보다 좋아지거나, 적어도 움직임 거절·파형복원·강건성에서 추가 가치를 보여야 한다.

## 호흡필터의 역할

저주파 추세와 빠른 잡음을 줄이고 호흡 주파수만 남겨 피크 탐색과 파형 비교를 안정화한다. 느린호흡부터 운동 후 빠른호흡까지 포함하므로 너무 좁은 고정대역은 일부 상태를 잘라낸다.

compact 전처리에서는 상태별로 다음 대역을 사용했다.

- 실험 1: 0.15~0.45 Hz
- 평소호흡: 0.15~0.50 Hz
- 느린호흡: 0.07~0.40 Hz
- 숨참기 후·스쿼트: 0.15~0.55 Hz
- 운동 후: 0.15~0.65 Hz

## 비교 결과

27명 947개 호흡수 창에서 신호처리 기준선은 창 전체 평균 0.992 bpm, subject-macro 0.994 bpm이었다. 같은 subject-macro 기준의 ANN은 1.528, 최선 SNN은 1.426 bpm으로 기준선보다 나빴다. 단순 신호처리가 현재 숫자상 최선이다.

## 중요한 공정성 문제

상태별 필터는 분석할 때 정답 상태를 알고 있다는 가정을 포함한다. 실제 환경에서 상태를 모르면 같은 필터를 고를 수 없으므로 완전한 UWB 단독 배포 기준선이라고 보기 어렵다. ANN/SNN 입력에도 이 상태별 전처리로 계산한 레이더 호흡수·품질 특징이 포함돼 있어, compact 모델 결과 역시 이 가정의 영향을 받는다.

## 다음 수정

최종 비교에서는 상태를 모르는 조건으로 공통대역을 사용하고, 같은 입력·같은 분할에서 신호처리·ANN·SNN을 다시 비교해야 한다. 72채널 파형 데이터셋은 이 문제를 줄이기 위해 공통 0.07~0.7 Hz를 사용했다.

## 결론

필터는 해야 좋은가라는 질문에는 `물리적으로 필요한 전처리지만, 시험 상태를 보고 대역을 고르면 불공정하다`가 답이다. 현재는 신호처리가 우세하며 SNN 사용 이유는 아직 성능으로 입증되지 않았다.
