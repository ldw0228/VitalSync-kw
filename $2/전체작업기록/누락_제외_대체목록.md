# 저장소 누락·제외·대체 목록

이 파일은 `업로드되지 않은 파일이 왜 없는지`를 추적하기 위한 목록이다. 조용히 빠뜨린 파일과 의도적으로 제외한 파일을 구분한다.

## 의도적으로 업로드하지 않은 원본

|항목|이유|저장소의 대체 자료|
|---|---|---|
|원시 UWB `.dat`|용량이 크고 피험자 원시 데이터임|읽기·전처리 코드, 피험자별 자동 검출 JSON, 결과 CSV|
|BIOPAC `.mat`|RSP·ECG 생체 원시 데이터임|마커 시각, 호흡수·심박 요약, 검증장부|
|회의 녹취 원본 DOCX/PDF|제3자 발화와 개인정보 가능성|014 상세기록과 피드백 텍스트|
|파형 데이터셋 NPZ|84,536,500바이트이며 원시 생체데이터 파생물|020 생성 코드·목록·요약·SHA-256|
|fold별 중간 체크포인트 75개 이상|정식 최종 모델이 아니며 저장소를 불필요하게 키움|fold 지표, 학습이력, OOF 예측, 최종 27명 모델 4개|
|렌더링 PNG·PDF 중간파일|문서 시각 검사용 중간 산출물|최종 DOCX와 구조 검증 결과|

## 데이터상 제외된 피험자

|피험자|제외 단계|이유|
|---|---|---|
|S01_CMS|27명 실험 1·2 모델|외부 경계 불명확|
|S22_KJH|27명 실험 1·2 모델|첫 경계 M01 누락|
|S24_KHJ|모든 UWB 분석|UWB 원본 없음|

## 모델 파일 분류

|구분|개수|의미|
|---|---:|---|
|초기 7분류 SNN|1|과거 목표의 파일럿|
|10명 연결시험 ANN/SNN|2|저장·재로딩 확인용|
|27명 compact ANN/SNN|4|교차검증 후 전체 학습한 배포 후보|
|파형 CNN-GRU/CNN-SNN|2|1폴드 파일럿 체크포인트|

`labeled_windows.npz`, `development_training_windows.npz`, `all27_training_windows.npz`는 모델이 아니라 파생 학습자료다. 모델 개수에 포함하지 않는다.

## 복원 가능성

제외된 중간파일은 로컬 작업 폴더에 남아 있고 Git 이전 커밋에도 기존 오분류 구조가 보존돼 있다. 현재 브랜치의 보이는 구조에서는 혼동을 줄이기 위해 작업 단계 중심 기록만 유지한다.
