# 대화 시작부터 현재까지의 전체 작업 기록

이 폴더는 실험 번호를 나열한 폴더가 아니다. 2026-08-29부터 2026-09-02까지 이 대화에서 실제로 요청받아 수행한 일을 시간순으로 복원한 연구·개발 이력이다. 각 번호는 하나의 작업 단계이며, 관련 엑셀·워드·모델·코드·수치 결과를 같은 폴더 안에 배치했다.

각 `상세작업기록.md`는 다음 질문에 답한다.

1. 당시 무엇을 요청받았는가.
2. 실제로 무엇을 했는가.
3. 왜 그 방법과 설정을 선택했는가.
4. 어떤 결과가 나왔는가.
5. 그 결과를 어디까지 믿을 수 있는가.
6. 다음 단계에서 무엇이 바뀌었는가.

## 먼저 볼 문서

전체 데이터 흐름, 싱크·마커 선택 근거, 데이터셋 구성, 모델 층·인코딩·에폭·학습률, 성능과 현재 한계를 그림과 함께 보려면 [전체기술보고서.md](전체기술보고서.md)를 먼저 읽는다. 그 뒤 아래 번호별 기록에서 실제 코드, 엑셀, CSV, 모델을 확인하면 된다.

## 중요한 해석 원칙

- `원시 자동 검출 수`는 BIOPAC RSP 임계값을 넘은 후보 수이지 실제 실험 마커 수가 아니다.
- 프로토콜상 마커 수는 S01~S03 피험자 코드에서 20개, S04 이후에서 22개로 판단했다. 22개는 실험 4의 추가 물건집기 한 쌍이 포함된 결과다.
- BIOPAC은 싱크, 라벨, 정답, 사후 평가에 사용했다. 실제 배포 모델의 입력은 UWB만 사용해야 한다.
- 10명 결과는 규칙을 만들면서 반복해서 본 개발 결과다. 독립 일반화 결과로 표현하지 않는다.
- 27명 최종 파일은 27명 전체로 다시 학습한 배포 후보이며, 예상 성능은 자기 학습 점수가 아니라 피험자 단위 교차검증 결과로 판단한다.
- 현재 학습 모델은 신호처리 기준선을 이기지 못했다. 따라서 SNN이 최종적으로 우월하다고 주장하지 않는다.

## 저장소에 넣지 않은 항목

원시 UWB `.dat`, BIOPAC `.mat`, 녹취 원본, 파형 학습 데이터셋 본체는 저장소에 넣지 않았다. 원시 생체데이터와 제3자 발화가 포함될 수 있고, 파형 데이터셋은 84,536,500바이트이기 때문이다. 대신 재현 코드, 입력 규격, 요약·목록·해시와 결과 파일을 남겼다. 상세 사유는 `누락_제외_대체목록.md`에 적었다.
