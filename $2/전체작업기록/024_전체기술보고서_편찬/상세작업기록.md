# 024 전체 기술보고서 편찬

## 요청

대화 처음부터 현재까지 무엇을 했는지 단순 파일 목록이 아니라, 판단 이유와 데이터 추출·라벨·학습·평가 과정을 한눈에 확인할 수 있는 정확하고 상세한 내부 문건으로 정리해 달라는 요청을 받았다. 실험 1~7을 폴더로 나누는 방식이 아니라 실제 작업 순서가 드러나야 했다.

## 수행 내용

- 001~023 단계의 상세기록, 코드, CSV, JSON, 저장 모델 설정을 다시 대조했다.
- 싱크, MATLAB 재검증, 원시 마커와 20/22개 프로토콜 마커의 차이를 하나의 흐름으로 설명했다.
- 10명 개발자료와 27명 피험자 단위 정식 평가를 명확히 구분했다.
- 초기 7종 SNN, compact ANN/SNN, CNN-GRU/CNN-SNN의 입력, 층, 파라미터, 인코딩, 손실, 에폭, 학습률, 배치와 조기종료 조건을 코드 기준으로 표로 만들었다.
- 실제 실행 결과에서 싱크, 마커 전수검사, 상태분류, 레이더 융합, 호흡수, 심박 그림을 선별했다.
- 27명 정식 compact 비교와 72채널 파형 파일럿을 평가 규모가 다르게 보이도록 한 장의 비교 그림으로 만들었다.
- 완료, 실패, 보류, 다음 단계와 발표 때 주장하면 안 되는 내용을 분리했다.

## 왜 이렇게 구성했는가

수치만 나열하면 초기 시나리오 분류의 높은 정확도, 10명 개발결과, 27명 정식 비교, 1폴드 파형 파일럿이 같은 수준의 증거처럼 보인다. 이를 막기 위해 모든 결과에 개발, 정식, 파일럿 성격을 표시하고, 앞 단계의 문제가 다음 설계 변경으로 어떻게 이어졌는지 설명했다.

새 장식용 그림을 대량 생성하지 않았다. 실제 결과 그림을 재사용하고, 새로 만든 비교 그림도 원 CSV와 JSON의 수치만 사용했다.

## 결과

전체 보고서는 상위 폴더의 [전체기술보고서.md](../전체기술보고서.md)에 있다. 대표 그림은 [시각자료](../시각자료) 폴더에 있다.

보고서의 현재 핵심 결론은 다음과 같다.

- MATLAB과 재구현의 원시 마커 검출은 재현됐지만 프로토콜 마커 선택은 별도 판단이다.
- 27명 정식 비교에서 최선 SNN은 subject-macro 1.426 bpm이며 같은 기준의 신호처리 0.994 bpm보다 나쁘다. 신호처리의 창 전체 평균은 0.992 bpm이다.
- 72채널 파형 모델은 아직 1폴드·1시드 파일럿이므로 최종 성능 주장을 하지 않는다.
- 다음 정식 비교는 공통 전처리, 피험자 분할 고정, BIOPAC 입력 금지, 동일 평가조건을 지켜야 한다.

## 한계

이 단계는 기존 분석을 종합한 문서화 단계이며 새로운 학습을 실행한 단계가 아니다. 따라서 이전 결과의 증거 수준을 높이지 않으며, 미완료인 72채널 정식 교차검증을 완료한 것처럼 표현하지 않는다.
