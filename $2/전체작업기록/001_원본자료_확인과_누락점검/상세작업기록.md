# 001 원본자료 확인과 누락점검

## 요청과 목적

처음 요청은 실험 안내 PPT, 마커를 적을 엑셀, `sync_tool_S02.m`을 이용해 각 시나리오 시간을 정리하는 것이었다. 이어서 공유 드라이브에서 가져온 파일에 누락이 있는지, 전체 폴더를 다시 내려받는 편이 나은지 확인해 달라는 요청이 추가됐다. 따라서 분석에 앞서 원본 구조와 누락을 확인했다.

## 실제 수행

- 실험 안내 PPT의 텍스트와 전체 슬라이드 구성을 추출해 시나리오 순서와 예정시간을 확인했다.
- `HAI_EXPERIMENT`의 피험자별 폴더, 레이더 1·2·3, BIOPAC 파일을 공유 폴더 목록과 대조했다.
- 당시 로컬에 없던 UWB 데이터 파일 41개를 25개 피험자 코드에서 식별했다.
- 내려받기 스크립트는 이미 존재하는 파일은 건너뛰고, 임시 `.part` 파일로 받은 뒤 크기를 검사하고 최종 이름으로 옮기도록 작성했다.

## 왜 먼저 했는가

싱크는 BIOPAC과 UWB가 모두 있어야 계산할 수 있다. 한 레이더라도 일부 누락되면 3레이더 평균 움직임과 경로 비교가 달라지고, UWB 전체가 없으면 싱크·학습·검증 자체가 불가능하다. 누락을 숨긴 채 모델을 만들면 피험자 수와 성능을 과대 보고하게 된다.

## 결과와 판단

대부분의 누락 파일은 보완됐지만 S24_KHJ는 최종 확인에서도 BIOPAC만 있고 UWB 원본을 찾지 못했다. 따라서 S24는 싱크와 UWB 모델에서 제외했다. 공개 목록에서는 공유 드라이브 파일 ID를 제거하고 피험자·레이더·녹화명·파일명만 남겼다.
