# 020 72채널 파형 데이터셋 구축

## 목적

compact 특징 모델이 신호처리를 이기지 못했고 상태별 필터에 의존했기 때문에, 레이더의 다중경로 I/Q와 위상 시계열을 더 많이 보존해 호흡 파형 자체를 복원하는 데이터셋을 만들었다.

## 입력 구성

- 피험자 27명
- 창 길이 20초, 이동 간격 5초
- 모델 샘플링 10 Hz, 200시점
- 레이더 3대
- 레이더당 경로 후보 8개
- 경로당 백색화 I, 백색화 Q, 공통대역 위상 3채널
- 총 입력 `3×8×3 = 72채널`, 형상 `72×200`
- 공통 호흡대역 0.07~0.7 Hz

경로 선택에는 UWB만 사용하고 BIOPAC은 목표 파형과 호흡수 정답에만 사용했다. 상태명은 창을 정의할 때 사용했지만 모델 입력에는 넣지 않았다.

## 데이터 규모

총 1,564개 창이며 파형·호흡수 정답이 유효한 창은 1,325개다. 움직임 양성 182개, 움직임 불명 7개, 무호흡 양성 50개다. 상태별 창은 방향·평소·느린호흡·숨참기·회복·스쿼트·운동 후를 포함한다.

## 왜 84MB 데이터 본체를 올리지 않았는가

`waveform_training_dataset.npz`는 84,536,500바이트이고 원시 생체데이터에서 직접 파생된다. 저장소에는 생성 코드, 창 목록, 요약, 제외 목록만 올렸다. 로컬 본체의 SHA-256은 `42a572ad995dd365ced6ec1d0605fc7d41d75fbd2974e36bc6fabe2d89098528`이다. 같은 원본과 코드로 재생성했는지 확인할 수 있다.

## 한계

8개 경로는 물리적으로 확인된 반사경로가 아니라 신호 품질 기반 후보다. 빈 환경 차감과 안테나·방 배치 기하가 없어 실제 LoS/고스트를 구분하지 못했다. 데이터셋 생성 완료는 모델 성능 성공을 뜻하지 않는다.
