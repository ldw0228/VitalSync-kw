# 014 발표 녹취와 피드백 검토

## 검토 목적

프로젝트 발표 녹취와 피드백을 읽어 기존 분석 방향이 실제 지도 의견과 맞는지 확인했다. 원문 녹취에는 제3자의 발화가 포함될 수 있어 저장소에는 넣지 않고, 피드백 텍스트와 반영 내용을 기록했다.

## 피드백에서 추출한 핵심 요구

- I/Q 위상 차이와 파형 보정을 포함한 전처리·디노이징을 설명할 것
- 직접 반사 경로만 보지 말고 주변 물체를 거친 보조 반사 경로도 활용할 것
- 정면 경로가 약할 때 보조 경로에서 호흡이 더 잘 보일 수 있다는 가설을 시험할 것
- 실험 1, 실험 2, 왕복을 우선하고 낙상·복잡 동작은 도전 과제로 둘 것
- 잘되는 피험자와 안 되는 피험자를 함께 제시하고 실패 원인을 설명할 것
- 관련 연구의 주장과 수치를 그대로 믿지 말고 재현 조건과 한계를 비판적으로 볼 것
- 호흡수뿐 아니라 가능하면 호흡 파형 복원을 보여 줄 것

## 반영한 결정

방향 분류 자체보다 3레이더·다중경로를 이용한 호흡 경로 선택과 파형 복원으로 목표를 바꿨다. 직접경로와 보조경로 후보를 모두 보존하고, 성공 사례만 고르지 않고 피험자 단위 성능을 보고하도록 했다. BIOPAC 이상 가능성과 정상 성인 호흡수 범위도 품질검사 항목으로 남겼다.

## 반영하지 못한 항목

빈 환경 측정 파일을 명확히 식별하지 못해 환경 차감은 실행하지 못했다. 반사 후보가 실제 물리적 고스트인지 확인할 공간 기하·추가 실험도 없었다. MoRe-FI, RF-Care 등은 후속 문헌조사 대상으로 기록했지만 이 단계에서 체계적 문헌 재현까지 완료한 것은 아니다.
