# 022 모델 독립 실행과 재현성 확인

## 질문

모델 파일 하나를 다른 환경으로 옮겨도 대화형 도움 없이 판정할 수 있는지, 모델은 어디에 있고 어떤 코드와 라이브러리로 실행하는지 확인해 달라는 요청이었다.

## compact 최종 모델 형식

018의 `.npz` 파일에는 가중치뿐 아니라 입력 형상, 인코딩 방식, 정규화 평균·표준편차, 호흡수 역정규화 값과 메타데이터가 함께 저장돼 있다. `predict_final_model.py`는 NumPy만으로 direct, signed-rate, delta-event 인코딩과 ANN/LIF SNN forward를 수행한다.

입력은 이미 전처리된 NPZ여야 한다.

- `waveforms`: `[N,150,6]`
- `scalars`: `[N,27]`
- 선택적으로 `subjects`, `starts`

출력 CSV는 창별 호흡수, 움직임 확률, 움직임에 따른 거절 표시를 낸다. BIOPAC은 추론 입력에 필요하지 않다.

## 재로딩 확인

저장된 최종 모델을 다시 읽어 1,082개 창을 추론했고 호흡수 예측 1,082개가 모두 유한값이었다. 움직임 거절은 133개 창에서 발생했다. 결과는 `final_model_reload_check.csv`에 남겼다.

## 독립 실행의 범위

모델 추론 자체는 저장 파일과 NumPy 코드로 가능하다. 그러나 원시 `.dat`에서 `waveforms`와 `scalars`를 만드는 전처리까지 모델 파일 하나에 포함된 것은 아니다. 완전한 배포 패키지라면 원시 UWB 읽기, 싱크 없는 연속 창 생성, 공통대역 전처리, 채널·경로 선택을 하나의 고정 파이프라인으로 묶어야 한다.

## 모델별 상태

- 초기 7분류 SNN: 독립 파일이지만 현재 목표와 다름
- 10명 ANN/SNN: 연결시험용
- 27명 compact 4개: 재로딩 가능한 배포 후보, 최선은 delta-event SNN
- CNN-GRU/CNN-SNN: 1폴드 파일럿 체크포인트, 최종 모델 아님

## 결론

`모델 파일을 불러와 전처리된 UWB 창을 판정`하는 기능은 확인했다. `원시 레이더 파일만 넣으면 자동으로 최종 판정`하는 완제품 상태는 아직 아니다.
