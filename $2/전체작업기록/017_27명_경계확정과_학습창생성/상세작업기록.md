# 017 27명 경계확정과 학습창 생성

## 왜 다시 만들었는가

초기 전체 프로토콜 엑셀과 10명 개발 라벨을 그대로 늘리지 않고, 정식 모델 전에 실험 1·2 경계와 학습 전처리를 27명 전체에 대해 다시 고정했다. 경계를 모델 성능을 보고 계속 바꾸면 시험자료에 맞춘 누수가 생기기 때문이다.

## 사용·제외 피험자

사용 가능한 27명은 S02~S21, S23, S25~S30 중 UWB·BIOPAC과 필요한 경계가 확보된 코드다. 다음 3명은 제외했다.

- S01_CMS: 실험 1·2 외부 경계가 불명확
- S22_KJH: 첫 경계 M01 누락
- S24_KHJ: UWB 원본 없음

27명 모두에서 실험 1 회전경계는 안내 예정시각 근처 레이더 움직임 피크로 찾았다. 숨참기 종료는 8명에서 RSP 재호흡으로 찾았고, 19명은 프로토콜 예정 30초를 사용했다.

## 학습창 설정

- 창 길이 30초, 이동 간격 5초
- 원본 UWB 40 Hz를 모델 시계열 5 Hz로 축소
- 시계열 150시점
- 3레이더의 위상과 변화량 6채널
- 레이더별 품질·스펙트럼·움직임·호흡수와 합의도 등 스칼라 27개
- 같은 피험자의 모든 창은 한 분할 역할에만 배치
- BIOPAC RSP는 호흡수 정답과 평가에만 사용

## 결과

총 1,082개 창을 만들었고 호흡수 정답이 유효한 창은 947개, 움직임 양성 130개, 움직임 불명 5개였다. 피험자별 창 수는 39~41개로 비교적 균등했다. 단순 신호처리 기준선은 전체 창 MAE 0.992 bpm, 피험자별 MAE를 평균한 subject-macro MAE 0.994 bpm이었다.

## 중요한 한계

이 compact 전처리는 상태별 호흡 대역을 사용했다. 예를 들어 느린호흡은 0.07~0.4 Hz, 운동 후는 0.15~0.65 Hz다. 상태 라벨을 실제 배포 시 알 수 없다면 이 전처리는 그대로 사용할 수 없다. 이 문제 때문에 뒤의 파형 데이터셋은 공통 0.07~0.7 Hz 대역을 사용했다.

## 산출물

피험자별 경계 결정, 전처리 설정, 창 목록·NPZ, 제외 목록, 프로토콜 잠금 기록과 생성 코드를 보존했다.
