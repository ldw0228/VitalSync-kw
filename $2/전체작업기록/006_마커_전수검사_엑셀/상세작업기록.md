# 006 마커 전수검사 엑셀

## 요청

기존 시트를 복사해 모든 피험자를 전수검사하고, 마커 하나를 고르기 애매하면 후보군을 적으며, 원시 값을 한 셀에 하나씩 놓고 선택된 셀을 색으로 확인할 수 있게 해 달라는 요청이었다.

## 구성 원칙

- 자동 원시 후보는 정렬된 시각 순서대로 한 셀에 하나씩 보존했다.
- 선택되지 않은 후보는 회색 음영으로 표시해 삭제하지 않았다.
- 선택 후보와 대체 후보를 구분했다.
- 프로토콜상 필요한 수, 자동 검출 수, 최종 선택 수를 나란히 적었다.
- 경계는 M01, M02처럼 순서 식별자를 부여할 수 있도록 원시 자료 구조를 만들었다.
- 예정시간과 실제 간격이 크게 다른 사례는 자동 확정하지 않고 재검토 대상으로 남겼다.

## 왜 원시값을 셀 단위로 남겼는가

시나리오 셀에 `12~205`처럼 반올림된 값만 있으면 어떤 원시 후보를 채택하거나 버렸는지 추적할 수 없다. 원시 배열을 셀 단위로 펼치면 선택 규칙을 다른 사람이 다시 적용할 수 있고, 자동화 코드가 잘못 고른 마커도 되돌릴 수 있다.

## 결과

30개 피험자 코드에 대해 프로토콜 수, 원시 후보, 선택값, 경계 쌍과 특이사항을 결합했다. S01~S03은 20개 규칙, S04 이후는 22개 규칙을 적용했다. 선택값이 부족하거나 UWB가 없는 사례는 빈칸을 임의 숫자로 채우지 않았다.
