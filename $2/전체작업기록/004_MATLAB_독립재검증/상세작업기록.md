# 004 MATLAB 독립 재검증

## 요청

자동 결과가 실제로 제공받은 MATLAB 코드와 같은지, 복사본을 만들어 직접 다시 돌리고 사용자가 볼 수 있는 내부보고서를 작성해 달라는 요청이었다. 원본 코드와 원본 데이터는 수정하지 않았다.

## 검증 방법

`sync_validate_batch.m`은 대화형 점선 이동과 저장 버튼을 제거하고 제공 코드의 데이터 읽기, RSP 마커 검출, 3레이더 움직임 계산, 오프셋 탐색을 모든 피험자에게 반복하도록 만든 검증용 사본이다. 별도의 일괄 구현도 같은 기본 임계값 8.5 V, 4초 병합, `-12~+12초/0.1초` 탐색을 사용했다.

두 실행에서 다음을 피험자별로 비교했다.

- 자동 원시 마커 개수
- BIOPAC 원시 마커 시각 배열
- 자동 오프셋
- 레이더축으로 변환된 마커 시각

## 결과

UWB 원본이 있는 29명은 자동 원시 마커 개수와 시각이 일치했다. 최대 차이는 S27에서 약 `2.84×10^-14초`로 부동소수점 표현 오차 수준이었다. S24는 양쪽 모두 UWB 없음으로 실패했다.

이 결과가 의미하는 것은 `자동 원시 검출 로직`이 두 구현에서 같다는 것이다. 이후 20개·22개 선택, 실험별 쌍 분할, 수동보정까지 자동으로 동일하다는 뜻은 아니다. 서로 다른 작업본이 달랐던 핵심 원인은 원시 데이터가 아니라 선택·분할 규칙이었다.
