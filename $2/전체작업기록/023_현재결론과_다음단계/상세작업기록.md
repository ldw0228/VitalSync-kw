# 023 현재 결론과 다음 단계

## 현재 연구 질문

실제 환경에서는 BIOPAC 없이 3개 UWB만 사용한다. 개발 중 BIOPAC RSP는 싱크·라벨·호흡 파형·호흡수 정답에, ECG는 심박 탐색 정답에만 사용한다. 현재 핵심 질문은 `3레이더와 다중경로 후보를 이용해 방향·움직임 변화에도 호흡 파형, 호흡수, 신뢰도 또는 거절 판단을 낼 수 있는가`다.

## 완료된 것

- 원본 구조와 누락 점검
- 제공 MATLAB 로직과 일괄 구현의 자동 원시 마커 일치 검증
- 프로토콜 20개/22개 규칙과 원시·선택값 분리
- 원시 후보, 번호, 색, 메모를 포함한 마커 검증장부
- 초기 7분류 SNN과 그 한계 확인
- 실험 1·2 세부 라벨과 운동 마커 오인 검사
- 방향·보조경로·숨참기 심박 탐색
- 10명 개발 신호처리 기준선
- 27명 경계·1,082개 compact 창·피험자 단위 교차검증
- 27명 ANN/SNN 최종 파일과 독립 재로딩 확인
- 72채널 파형 데이터셋과 GRU/SNN 1폴드 파일럿

## 아직 완료되지 않은 것

- 재검토 마커가 남은 피험자의 전 프로토콜 수동 확정
- 원시 UWB부터 최종 출력까지 하나로 묶인 배포 파이프라인
- 상태를 모르는 공통 전처리 조건에서 compact 모델 재평가
- 파형모델의 5폴드×3시드 정식 비교
- 모델 튜닝과 시험 피험자의 완전 분리
- 빈 환경 차감과 물리적 멀티패스/고스트 확인
- 외부 피험자·새 방·새 자세에서의 검증
- SNN의 에너지·지연 이점 측정

## 현재 숫자로 가능한 결론

27명 compact 비교에서 최선 SNN은 subject-macro 1.426 bpm이고 같은 기준의 신호처리는 0.994 bpm이다. 신호처리의 창 전체 평균은 0.992 bpm이다. 현재는 신호처리가 더 낫다. 파형 파일럿도 GRU 3.843 bpm, SNN 4.595 bpm으로 충분하지 않다. 따라서 SNN 우월성을 주장할 단계가 아니다.

## 다음 작업 순서

1. 상태 라벨을 사용하지 않는 공통 전처리를 고정한다.
2. 개발 fold에서만 필터·경로·모델을 튜닝한다.
3. 같은 5폴드×3시드에서 신호처리, ANN, GRU, SNN을 비교한다.
4. 호흡수 MAE뿐 아니라 파형 상관, 움직임 거절 후 coverage, 피험자별 성공·실패 사례를 함께 보고한다.
5. 최종 선택 모델과 전처리 코드를 하나의 원시 UWB 추론 패키지로 만든다.

## 발표 시 정직하게 말해야 할 내용

싱크 재현성과 데이터 감사 체계는 확보했다. 3레이더 공간 다양성과 보조 경로 후보가 도움이 될 가능성은 있으나 개선폭은 아직 작다. 학습모델은 현재 신호처리를 이기지 못했다. 이 실패와 개선계획까지 포함하는 것이 현재 가장 정확한 프로젝트 상태다.
