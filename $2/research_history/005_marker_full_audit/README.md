# 005 마커 전수검사

피험자 S01~S03은 20개(10쌍), S04~S30은 22개(11쌍)다. 추가 1쌍은 실험4의 물건집기이며 검출 후 임의로 쪼갠 것이 아니다. 자동 원시 검출은 프로토콜보다 적은 17명, 같은 3명, 많은 10명이어서 개수만으로 경계를 정할 수 없었다. [`marker_counts.md`](marker_counts.md)에 전체 수를 적었다.

예정시간은 실험1 150~240초, 실험2 240~450초, 픽업 각 5~90초, 낙상 3조건, 추가 픽업 5~40초, 코스 130~230초, 왕복·자유행동 각 5~70초로 점검했다.
