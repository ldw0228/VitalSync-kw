# Data Policy

This repo should not contain raw UWB/BIOPAC data or subject-level exports.

Do not commit:

- raw `.mat` files
- exported training datasets such as `snn_holdout_dataset.mat`
- subject/window-level CSV files
- trained model weights such as `.pt`, `.pth`, `.mat` workspaces
- files containing subject names or personally identifying metadata

Allowed in this folder:

- source code
- aggregate figures
- aggregate metric summaries
- documentation explaining the analysis approach
