## 중기 과제

**운동 후 호흡 구간.** 지금 제일 약하다(고전 2.58, 모델 2.29). 이 구간은 **상한 자체가 1.45**로
다른 구간(0.11~0.44)보다 훨씬 높다 — 후보 안에 정답이 잘 들어 있지 않다는 뜻.
체동이 큰 구간을 위한 별도 처리가 필요하다.

**입력 표현 확장.** 현재 SNN 입력은 후보별 1차원 파형 하나. MoRe-Fi 방식대로 거리 칸 여러 개의
I·Q를 다채널로 넣으면 달라질 수 있다. 단, end-to-end 시도가 데이터 규모로 실패했으므로
**나머지 30명 데이터가 온 뒤**가 적기다.

**진짜 멀티패스 활용.** r3의 +30 bin 2차 반사가 일관되게 존재하고 49%가 같은 호흡 주파수를
갖는다. 회의 조언대로 신호 복원에 넣어볼 가치가 있다.

**거리 정규화.** 각도 과제에서 r1+r3 학습 → r2 검증이 58.3%로 떨어졌다.
진폭이 거리의 4제곱에 반비례하므로 1/r⁴ 보정 후 재실험.

**상태 분류 부 과제.** 호흡 상태 6분류를 같은 인코더에 출력 머리만 붙여 추가.
회복 호흡 라벨은 18~46초로 좁힌 버전(`dataset_B2.npz`)이 준비되어 있으나 학습 미실행.

## 방법론상 남은 위험

| 위험 | 내용 |
|---|---|
| 겹치는 창 | 3,696개는 독립 표본이 아니다. 실질적으로 28명 × 4구간 = 112블록. 논문에 쓸 때 이렇게 적어야 함 |
| 세션 정규화 의존 | 레이더별 크기 정규화를 창 안에서 하고 있음. 실사용 시 보정 구간이 필요한지 미확인 |
| 파형 복원의 정렬 한계 | 싱크 정밀도가 중앙값 1.1초·σ 4.5초. 파형 복원에는 부족. 위상 둔감 손실로 우회했으나 근본 해결은 아님 |
| 데이터 규모 | 앉아서 호흡한 구간이 2시간 남짓. MoRe-Fi는 66시간. 나머지 30명이 와도 4시간 |
