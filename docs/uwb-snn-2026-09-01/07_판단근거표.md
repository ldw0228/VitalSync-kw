# 07. 판단 근거표

모든 설정값과 설계 결정에 대해 **왜 그 값인지**, **표준을 따른 것인지 우리가 정한 것인지**를 적는다.

---

## A. 설계 결정

| 결정 | 근거 | 출처 |
|---|---|---|
| I/Q 파싱을 전후분할로 수정 | 184값을 짝/홀로 뽑으면 같은 표적이 46 bin(92의 절반) 떨어져 두 번 나타남. 앞 92=실수, 뒤 92=허수로 읽으면 봉우리가 하나로 모임 | 실제 파일 3방식 비교 |
| 마커 기반 offset 추정 폐기 | 전·후반부 추정이 ±20초씩 어긋나고 레이더 3대가 서로 다른 값. 신뢰도 0~1.6 | 29명 실험 |
| 지형지물 정박으로 전환 | 회전 봉우리·무호흡은 레이더가 직접 보는 사건이라 offset이 불필요 | 28명 검출 |
| 회전1을 50~120초로 제약 | 네 지형지물이 모두 62초 간격이라 아무 쌍이나 잡힐 수 있음. 제약 후 잘못 잡힌 4명 교정 | 제약 전/후 비교 |
| 각도를 레이더별 상대각으로 재정의 | 블록당 표본 1→3개, 입력이 레이더 1대가 됨 | 사용자 제안 |
| 부호 없는 \|각도\|를 목표로 | 레이더1은 음의 각도만, 레이더3은 양의 각도만 관측 → 부호가 레이더 정체성과 완전 상관. 5분류면 "몇 번 레이더인지"를 외워 맞힐 수 있음 | 관측 각도표 |
| 가슴 피크 주변으로 range bin 정렬 | r2가 1.41배 멀어 사람이 잡히는 bin이 다름(r1·r3≈29, r2≈39). 그대로 두면 bin 번호가 정체성 단서 | 기하 검증 |
| 학습 전 물리 검증을 통과 조건으로 | 신호에 각도가 안 보이면 학습은 시간 낭비 | 28명 252표본 |
| 등거리 레이더로 일반화 검증 | r1·r3이 등거리이므로 거리를 고정한 채 "각도를 배웠는가"만 물을 수 있음 | 배치 기하 |
| 회복 호흡 라벨 재정의 | 회복 반응은 무호흡 후 20초까지만 뚜렷(진폭 1.35→1.09). 62초 라벨의 3분의 2가 평소 호흡과 같은 신호 | BIOPAC 25명 재분석 |
| 과제를 호흡수·파형으로 전환 | 각도 자체를 목표로 삼는 논문이 거의 없음. 몸 방향은 극복 대상이지 답이 아님 | 문헌 조사 |
| 모델 임무를 "후보 선택"으로 정의 | 중앙값 융합 1.61 → 최선 선택 0.32. 5배 격차. 최선 레이더가 38/36/38로 균등해 고정 규칙 불가 | 기준선 분석 |
| 되먹임 필터로 배경 제거 | 빈 방 녹화가 없음. SVD 대체법은 악화(2.13→3.63). 논문 방식은 녹화 자체에서 배경 추정 | MoRe-Fi |
| 지형지물로 자르고 마커로 검증 | 지형지물이 더 정확(1.33 vs 1.78)하고 커버리지 넓음(28 vs 21명). 마커는 개수가 5~48개로 불안정하나 검증에는 유용 | 21명 짝지은 비교 |
| 학습/검증/평가 3분할 | 평가셋으로 에폭을 고르면 최대 0.29 부풀려지고 결론까지 바뀜 | 교정 전후 비교 |

## B. 신호처리 설정

| 설정 | 값 | 표준? | 근거 |
|---|---|---|---|
| 표본율 | 40 fps → 10 Hz | 우리가 정함 | 호흡은 0.2~0.5 Hz. 나이퀴스트 대비 10배 여유 |
| 대역통과 | 0.06 ~ 0.80 Hz | 우리가 정함 | 하한은 서파 호흡 4회/분(0.067 Hz), 상한은 운동 후 40회/분(0.67 Hz)을 담기 위함 |
| 되먹임 필터 β | 0.98 | **논문값(0.9)에서 변경** | 10 Hz에서 β=0.9는 차단 ~0.16 Hz라 호흡 대역을 갉아먹음. 0.98이면 ~0.03 Hz |
| 가슴 bin 탐지 | 0.1~0.6 Hz 대역통과 후 분산 최대 | 표준 | 레이더 vital-sign 문헌의 일반적 방식 |
| bin 절취 폭 | 가슴 ±8 (17칸) | 우리가 정함 | 체동으로 몇 칸 움직여도 담기도록. 탐색 안 함 |
| 복조 | I/Q 주성분 투영 | 표준 | 다만 MoRe-Fi는 1차원 투영을 거부 — 06번 참조 |
| 호흡수 추정 | 스펙트럼 정점 + 포물선 보간 | 표준 | 격자 양자화(30초 창에서 1.18 회/분) 제거 |
| 창 | 30초, 5초 이동 | 표준 | 30초면 호흡 3~10주기. 겹침 슬라이딩은 생체신호 ML의 기본 |
| 융합 | 3대 중앙값 | 표준 | 이상치에 강함. 다만 2대가 함께 틀리면 실패 — 04번 참조 |

## D. 인코딩 5종

| 인코딩 | 정의 | 파라미터 | 왜 넣었나 |
|---|---|---|---|
| direct | 아날로그 값을 매 step 전류로 주입 (엄밀히는 스파이크 아님) | — | 최근 SNN 논문의 기본값. "스파이크가 정말 도움이 되는가"의 기준선 |
| rate | [0,1]로 눌러 Bernoulli 표본, 양·음 2채널 정류 | hi=2.0 | 가장 고전적인 레이트 부호화 |
| delta | 인접 step 차이가 임계를 넘으면 ON/OFF 발화 | th=0.3 | DVS 이벤트 카메라 방식. 가장 희소 |
| step-forward | 내부 기준선을 추종하며 계단으로 부호화 | th=0.4 | 신호를 재구성 가능한 수준으로 보존하는 레벨 부호화 대표 |
| population | 가우시안 수용장 5개에 대한 응답이 임계를 넘으면 발화 | M=5, lo/hi=∓2, th=0.55 | 연속량 표현의 표준 |

**임계값들은 우리가 정했고 탐색하지 않았다.**

## E. 평가 지표

| 지표 | 정의 | 왜 이것인가 |
|---|---|---|
| **MAE (회/분)** | 추정 호흡수와 BIOPAC 정답의 절대 차이, 전체 평균 | 레이더 vital-sign 논문의 표준 지표 |
| 1회/분 이내 비율 | \|오차\| ≤ 1.0 인 창의 비율 | 평균은 소수의 큰 실패에 끌려감. 분포를 함께 봐야 함 |
| 2.5회/분 이내 비율 | \|오차\| ≤ 2.5 | 회의에서 "2.5는 많이 틀리는 것"이라는 기준이 제시됨 |
| 파라미터 수 | 모델 가중치 개수 | SNN의 논지가 경량화이므로 필수 |
| 조기종료 에폭 | 검증셋 최고 지점 | 과적합 속도 비교용 |
