# 실험 6 · 학습 전 물리 검증

> **판정: 통과.** 신호 수준에서 각도가 보인다는 것을 확인하고 학습에 들어갔다.

## 왜 했나
신호 수준에서 각도가 보이지 않으면 학습은 시간 낭비다.
**학습 전에 통과 조건**으로 걸어두었다 — 결과를 보고 사후에 해석하지 않기 위해.

## 무엇을 했나
피험자·레이더별로 3블록 평균을 1로 정규화한 호흡 변조 진폭을 쟀다.

| 각도 | 진폭 | 95% 신뢰구간 |
|---|---|---|
| 0° (정면) | 1.456 | ±0.064 |
| 45° | 0.836 | ±0.039 |
| 90° (측면) | 0.645 | ±0.049 |

![각도별 호흡 변조 진폭](../../assets/c_phys.png)

## 통계
t검정 — 0 vs 45: p=1.5e−15 · 45 vs 90: p=4.0e−03 · 0 vs 90: p=5.6e−16.
**28명 전원**이 0°/90° 비율 1 초과 (중앙값 2.67배).

## 왜 이런 결과가 나오나
가슴이 앞뒤로 움직일 때, 정면에서 보면 그 움직임이 레이더 시선 방향과 나란해서 위상 변화가 크다.
측면에서 보면 시선에 수직 성분이 커서 변화가 작다. 예상대로 나온 것.
