## 왜 했나
지형지물([실험 5](../05_동기화_지형지물/))로 자른 것이 마커 기반보다 나은지 확인해야 했다.

**중요:** 이전 세션에서 팀과 함께 만든 `HAI_동기화_종합.xlsx`에 마커 기반 구간이
**이미 정리되어 있었다.** 처음에는 이 파일을 쓰지 않고 즉석 규칙("3번째 마커가 실험2 시작")으로
비교해 마커 쪽에 불리한 결과를 냈다 — 지적받고 교정했다.
자세한 내용은 [06_실패기록.md §9](../../06_실패기록.md).

## 무엇을 했나
`HAI_동기화_종합.xlsx`의 실험2 구간(레이더 시간)을 기준으로 자른 것과,
지형지물로 자른 것을 **동일한 고전 추정기**로 비교. 조건은 자르기 하나만 다르게.

## 결과 (공통 21명, 창 각 588개)

| | MAE | 1회/분 이내 |
|---|---|---|
| 마커 기반 | 1.78 | 74% |
| 지형지물 기반 | **1.33** | **82%** |

21명 중 **13명**에서 지형지물이 나음.

구간별로 보면 **평소 호흡에서 차이가 제일 크고**(2.24 vs 0.65),
**회복 호흡에서는 오히려 마커가 낫다** — 한쪽이 전부 이기는 게 아니다.

## 커버리지 차이

| | 사용 가능 피험자 | 창 수 |
|---|---|---|
| 마커 기반 | 21명 | 588 |
| 지형지물 기반 | **28명** | **784** |

7명은 마커 경계가 검출되지 않아 마커 방식으로는 아예 쓸 수 없다.

## 마커 검증 — 두 방식은 서로 확증한다
"몇 번째 마커"가 아니라 **"가장 가까운 마커"**로 대조하면 **21명이 5초 안에서 일치**.

| 기준점 | 평균 차 | 표준편차 |
|---|---|---|
| 실험1 시작 | +4.8초 | 3.3초 |
| 실험1 종료 | −5.2초 | 3.4초 |
| 실험2 시작 | +4.1초 | 3.4초 |

계통적으로 몇 초 어긋나는 것은 **정의 차이**다 — 마커는 실험 시작 순간을 누른 것이고,
우리 블록은 회전 봉우리 기준. **팀의 마커 작업이 틀렸던 게 아니라, 두 방식이 서로를 확인해 준다.**

## 마커가 불안정한 이유
마커 개수가 **5개에서 48개까지** 제각각 (기대 20~22개).
사람이 손으로 누른 것이라 누락·중복이 생겨 "3번째 마커가 실험2 시작" 같은 규칙이 성립하지 않는다.

## 결정
**지형지물로 자르고, 마커로 검증하고, 안 맞는 사람을 걸러낸다.**
