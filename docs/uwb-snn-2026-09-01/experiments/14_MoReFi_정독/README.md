# 실험 14 · MoRe-Fi 정독

> **판정: 우리 설계가 왜 틀렸는지가 논문에 그대로 적혀 있었다.**

## 왜 했나
[실험 13](../13_end2end_실패/) 실패 후, **선행연구를 제대로 읽지 않고 설계했다**는 것이 문제로 지적됨.
(그 전에 제가 "확인했다"고 말했으나 실제로는 제목과 초록만 본 상태였습니다 — 지적받고 본문을 읽었습니다.)

## 무엇을 읽었나
MoRe-Fi — *Motion-robust and Fine-grained Respiration Monitoring via Deep-Learning UWB Radar*,
SenSys 2021, arXiv 2111.08195.

## 논문이 우리 방식을 명시적으로 거부하는 대목
- 타원 적합은 **"정지 상태 피험자를 위해 설계된 것"**이라 움직이면 실패한다
- **"진폭이나 위상 어느 쪽 파형도 호흡을 제대로 표현하지 못한다"** — 1차원 투영을 명시적으로 거부

[실험 12](../12_후보선택기/)에서 만든 후보 9개는 **전부 그 1차원 투영**이었다.

## 논문이 실제로 하는 것

| | |
|---|---|
| 배경 제거 | 되먹임 필터 (β=0.9). **빈 방 녹화 불필요** |
| 사람 찾기 | CFAR 봉우리 검출 |
| 입력 | 봉우리 주변 여러 거리 칸의 I·Q를 **각각 다채널 시퀀스로** (1000×138). 1차원으로 압축하지 않음 |
| 증강 | I/Q 평면에서 0~2π를 π/30 간격으로 **60회 회전** |
| 구조 | I·Q 두 스트림 인코더(1D CNN 5층) → 2-Wasserstein 잠재공간 정렬 → 디코더 |
| 출력 | **호흡 파형.** 호흡수는 FFT로 파생 |
| 평가 | 코사인 유사도 (평균 0.9162) |
| 규모 | 12명 · 66시간 · 학습 8,000쌍 / 시험 4,000쌍 · 파라미터 **2,360만** |

## 우리와의 격차

| | MoRe-Fi | 우리 |
|---|---|---|
| 데이터 | 66시간 | 앉아서 호흡한 구간 약 2시간 |
| 학습 쌍 | 8,000 | 590~3,700 |
| 파라미터 | 2,360만 | 8천 |

**[실험 13](../13_end2end_실패/)이 실패한 이유가 여기 다 있다.**

## 무엇을 가져왔나
- **되먹임 필터 배경 제거 도입** → 기준선 1.66 → 1.55로 개선.
  단 β는 0.9가 아니라 **0.98**로 바꿨다 (10 Hz 재표본에서 0.9는 호흡 대역을 잘라먹음)
- 입력 형태를 논문 방식(다채널 I·Q)으로 교정
- 모델 규모는 우리 데이터에 맞게 축소 — 2,360만 파라미터를 590쌍으로 학습할 수는 없다
