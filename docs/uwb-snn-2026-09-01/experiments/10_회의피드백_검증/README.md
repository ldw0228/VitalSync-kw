# 실험 10 · 회의 피드백 검증

> **판정: 5건 확인, 1건은 조언과 다른 원인.** 다만 조언의 실질적 처방은 맞았다.

## 왜 했나
2026-08-31 회의 녹취록과 피드백 문서를 받았다. 각 항목을 **데이터로 확인**했다.

## 항목별 결과

### ① "위아래로 뜨는 한 쌍은 line-of-sight와 고스트다. 둘 다 써라"
**그 한 쌍은 고스트가 아니라 I/Q였다.**

| 근거 | 값 |
|---|---|
| 두 봉우리 간격 | 정확히 92 bin = 블록 크기 |
| 블록 내 같은 위치인 비율 | 87건 중 97% |
| 멀티패스라면? | 반사 경로가 더 길어 **더 먼 거리**에 나타나야 함 |

다만 두 줄의 파형 상관은 −0.15로 **실제로 다르고, 합쳐야 호흡이 복원된다.**
→ "둘 다 쓰라"는 처방 자체는 맞았다.

### ② 그럼 진짜 멀티패스는 있나
파싱 수정 후에도 **레이더 3의 +30 bin에 2차 반사**가 일관되게 존재.

| 레이더 | 위치 | 세기 | 같은 호흡 주파수 |
|---|---|---|---|
| r1 | +13 (−11~+33, 산발) | 0.22 | 48% |
| r2 | +21 (−25~+24, 산발) | 0.24 | 55% |
| **r3** | **+30 (+28~+32, 일관)** | **0.43** | 45% |

r3의 +30은 범위가 좁고 세기가 절반 이하로 줄어든, **멀티패스가 가져야 할 모습**을 갖췄다.
아직 신호 복원에 활용하지는 않았다.

### ③ 환경 파일로 배경 제거
**빈 방 녹화가 데이터에 없다.** 전달된 30명 폴더 어디에도 없음.
유일한 예외인 S01_CMS의 24분 추가 녹화도 사람이 있는 파일럿 촬영이었다(bin 30에서 11.7회/분 호흡).

대체법(SVD 지배성분 제거)을 25명 전원에 시험 → **오히려 악화.**

| 처리 | MAE | 해상도 이내 |
|---|---|---|
| 없음 | 2.13 | 80% |
| SVD 1성분 제거 | 3.63 | 60% |
| SVD 2성분 제거 | 4.28 | 55% |

앉아서 호흡하는 녹화에서는 **지배 성분이 곧 사람의 가슴 반사**이기 때문.
→ [실험 14](../14_MoReFi_정독/)의 되먹임 필터로 해결.

### ④ BIOPAC 이상 피험자 확인
25회/분 초과 **0명**. 주기 변동계수 최대 0.27로 전원 규칙적.

### ⑤ S01_CMS
**본 녹화가 12.5초(501프레임)** — 실험이 담기지 않음. 재촬영 요청 대상.

### ⑥ I/Q 위상 보정
타원 적합으로 구현·시험 → [실험 11](../11_기준선/) 참조.
느린 호흡에서 크게 개선(0.81→0.09)되나 체동 구간에서 무너져 전체로는 손해.
