## 과제 정의
창마다 **레이더 3대 × 복조 3방식 = 후보 9개**를 만들고,
각 후보의 호흡수 추정을 얼마나 믿을 수 있는지 모델이 점수로 매긴다.
점수가 가장 좋은 후보를 채택하고, 그 값과 BIOPAC 정답의 차이를 오차로 잰다.

## 왜 이 과제인가
[실험 11](../11_기준선/)에서 확인한 대로, 매번 최선을 고를 수 있으면 1.6 → 0.32까지 내려간다.
그리고 최선인 레이더가 균등하게 흩어져 고정 규칙으로는 닿을 수 없다.

## 입력

| | |
|---|---|
| 주 입력 | 후보별 호흡 파형 1채널 × 100 step (30초 @ 3.33 Hz) |
| 보조 특징 10종 | 배음비 h2·h3, 기본파 비중, 스펙트럼 엔트로피, 2등봉우리비, 전후 드리프트, 표준편차, 적합잔차, 레이더번호, 복조번호 |
| 후보 관계 특징 3종 | 추정값, 중앙값과의 차, 합의수(±1 BPM 이내 동의 후보 수) |
| 출력 | 후보별 신뢰도 점수 1개 → 가장 낮은 점수의 후보 채택 |
| 손실 | MSE(log(1+오차)) + 0.5 × CrossEntropy(최선후보) |

## 결과
1.18 회/분 (당시 방법론 기준). 기준선 1.66 대비 개선.

## 절제 실험 — 무엇이 성능을 만드나

| 조건 | MAE | 1회/분 이내 |
|---|---|---|
| 파형만 · 9개 공동 채점 (SNN) | 2.03 | 75% |
| 파형만 · 후보별 채점 (SNN) | 1.79 | 80% |
| 기준선 · 3대 중앙값 (학습 없음) | 1.66 | 79% |
| 신뢰도 특징만 (SNN 없음) | **1.34** | 87% |
| 특징 + SNN | **1.18** | 88% |

**레이더 파형만 주면 SNN은 기준선도 넘지 못한다.**
이득의 대부분이 손으로 만든 신뢰도 특징에서 나왔고, SNN 몫은 약 0.16.

## 이 결과가 불편했던 이유
"고전 신호처리가 만든 답 9개 중 하나를 고르는 심판"은 SNN에게 어울리는 역할이 아니다.
